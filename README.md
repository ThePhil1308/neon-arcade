# Neon Arcade

17 Browser-Spiele in einer Seite – mit dem 3D-Shooter NEON STRIKE.

**Spielen:** https://thephil1308.github.io/neon-arcade/

- Die ganze Seite steckt in einer Datei: `index.html`.
- NEON STRIKE lädt beim ersten Start die 3D-Bibliothek Three.js aus dem Internet.
- Highscores und Fortschritt bleiben auf deinem Gerät.
